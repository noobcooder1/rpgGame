UI Redesign Backup - 2026-06-05
================================

This folder preserves the pre-redesign UI files so the previous game screen can be restored easily.

Backed up files:
- `rpgmain.html`: previous game screen markup.
- `main.css`: previous UI styling.
- `mapSystem.js`: previous map/location UI update helpers.

To restore the old UI, copy these files back to their original locations:
- `rpgmain.html` -> project root `rpgmain.html`
- `main.css` -> project root `main.css`
- `mapSystem.js` -> `js/mapSystem.js`
